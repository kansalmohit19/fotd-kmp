# FOTDKMP

## Overview

FOTDKMP is a Kotlin Multiplatform project designed to share code between Android and iOS applications. It leverages Gradle for build management and supports both Kotlin and Java.

## Project Structure

- `androidApp/` — Android application module
- `iosApp/` — iOS application module (Swift)
- `shared/` — Shared Kotlin Multiplatform code (common, Android, iOS, native)

## Technologies

- Kotlin Multiplatform
- Java
- Gradle
- Android Studio
- Xcode (for iOS)

## Getting Started

### Prerequisites

- JDK 8 or higher
- Android Studio (latest)

- Gradle (or use the provided wrapper)
